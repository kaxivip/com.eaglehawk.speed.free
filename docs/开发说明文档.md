# 雄鹰加速器 - 原生/H5 开发说明文档

## 一、项目概述

**应用名称**：雄鹰加速器  
**应用类型**：网络加速工具（VPN/Proxy）  
**技术栈**：React 18 + TypeScript + Vite + Tailwind CSS  
**设计规范**：375px 宽度（iPhone SE 基准），深色海洋主题  

---

## 二、应用架构

### 2.1 导航结构

```
App
├── SplashPage (开屏)
├── Privacy (隐私协议 - 首次启动)
├── Main (主框架)
│   ├── BottomNav (底部导航)
│   │   ├── HomePage (首页/加速页)
│   │   ├── TaskCenterPage (免费会员/任务中心)
│   │   └── ProfilePage (我的)
│   └── LoginPage (登录弹层 - 覆盖层)
└── Sub Pages (子页面 - 全屏路由)
    ├── ModeSelectPage (模式选择)
    ├── AppSelectPage (应用选择)
    ├── LineSelectPage (线路选择)
    ├── SharePage (分享好友)
    ├── ShareDetailPage (分享明细)
    ├── OtherBenefitsPage (限量福利)
    ├── TaskSubmitPage (任务提交)
    ├── PointsExchangePage (积分兑换)
    ├── PointsHistoryPage (积分历史)
    ├── SettingsPage (设置)
    ├── AgreementPage (协议详情)
    ├── AccountDeletePage (注销账号)
    ├── OtherPlatformsPage (其他平台)
    ├── AboutPage (关于)
    ├── HelpCenterPage (帮助中心)
    └── BusinessCoopPage (商务合作)
```

### 2.2 全局状态

| 状态字段 | 类型 | 说明 |
|---------|------|------|
| `stage` | AppStage | 当前页面路由标识 |
| `isLoggedIn` | boolean | 登录状态 |
| `currentPage` | PageKey | 底部导航当前页 ("home"/"tasks"/"profile") |
| `isConnected` | boolean | VPN 连接状态 |
| `isConnecting` | boolean | 连接中状态 |
| `currentMode` | "global" \| "app" | 加速模式 |
| `currentLine` | LineId | 选择的线路 |
| `selectedApps` | string[] | 应用加速模式下选中的应用列表 |
| `memberMinutes` | number | 会员剩余时长（分钟），0=非会员 |
| `points` | number | 用户积分 |
| `remainingSeconds` | number | 当前加速剩余秒数 |
| `showLoginModal` | boolean | 登录弹层显示状态 |

## 四、业务逻辑

### 4.1 积分系统

#### 积分获取途径
| 途径 | 积分 | 频率限制 |
|-----|------|---------|
| 观看激励广告 | 50/次 | 每日8次 |
| 邀请好友注册（无邀请码） | 50 | - |
| 邀请好友注册（有邀请码） | 500 (10倍) | - |
| 好友30天内积分1:1返还 | 等额 | 30天内 |
| 福利任务 | 不定 | 积分>200可激活 |

#### 积分消耗
| 用途 | 消耗 |
|-----|------|
| 兑换30分钟会员 | 30 |
| 兑换1小时会员 | 60 |
| 兑换24小时会员 | 1200 |
| 兑换7天会员 | 7200 |
| 会员日24小时 | 500 |
| 会员日7天 | 1000 |

### 4.2 会员系统

**会员状态判定**：`memberMinutes > 0`  
**计时器逻辑**：
- 连接时设置 `remainingSeconds = memberMinutes * 60`
- 每秒递减
- 归零时自动断开连接

### 4.3 VPN 连接逻辑

**状态流转**：
```
未连接 → 点击 → 连接中(2秒) → 已连接
已连接 → 点击 → 未连接
已连接 → 时间归零 → 未连接
```

**连接参数**：
- 模式：global（全局）/ app（指定应用）
- 线路：smart / japan / usa / singapore / korea
- 应用列表：selectedApps[]

## 七、原生开发适配要点

### 7.1 iOS 适配

| 事项 | 说明 |
|-----|------|
| Safe Area | 顶部刘海区（已预留 h-12=48px）、底部 Home 指示条 |
| VPN 权限 | 首次连接需请求 VPN 配置权限 |
| 剪贴板 | UIPasteboard.general.string |
| 激励广告 | 接入 AdMob / AppLovin 等 SDK |
| PWA 提示 | AddToHomeScreenPrompt 组件提示添加到主屏幕 |

### 7.2 Android 适配

| 事项 | 说明 |
|-----|------|
| 状态栏 | 沉浸式，内容延伸至状态栏下方 |
| VPN 权限 | VpnService.prepare() 请求 |
| 剪贴板 | ClipboardManager |
| 后台运行 | VPN 服务需 Foreground Service |
| 返回键 | 子页面返回上一页，主页弹出退出确认 |

### 7.3 H5 适配

| 事项 | 说明 |
|-----|------|
| 视口 | viewport-fit=cover, user-scalable=no |
| 触摸 | touch-action: manipulation |
| 安全区 | env(safe-area-inset-*) |
| VPN 功能 | H5 无法实现真实 VPN，需跳转 App Store/应用市场 |
| 广告 SDK | 接入穿山甲、优量汇等 H5 版本 |
| 分享 | 微信 JS-SDK / 系统分享 API |
