一、项目概述

应用名称：雄鹰加速器

应用类型：网络加速工具（VPN/Proxy）

技术栈：React 18 + TypeScript + Vite + Tailwind CSS

设计规范：375px 宽度（iPhone SE 基准），深色海洋主题

4.2 会员系统

会员状态判定：memberMinutes > 0

计时器逻辑：

  • 连接时设置 remainingSeconds = memberMinutes * 60
  • 每秒递减
  • 归零时自动断开连接

4.3 VPN 连接逻辑

状态流转：

未连接 → 点击 → 连接中(2秒) → 已连接
已连接 → 点击 → 未连接
已连接 → 时间归零 → 未连接

七、原生开发适配要点

7.1 iOS 适配

事项说明
Safe Area顶部刘海区（已预留 h-12=48px）、底部 Home 指示条
VPN 权限首次连接需请求 VPN 配置权限
剪贴板UIPasteboard.general.string
激励广告接入 AdMob / AppLovin 等 SDK

7.2 Android 适配

事项说明
状态栏沉浸式，内容延伸至状态栏下方
VPN 权限VpnService.prepare() 请求
剪贴板ClipboardManager
后台运行VPN 服务需 Foreground Service

7.3 H5 适配

事项说明
视口viewport-fit=cover, user-scalable=no
触摸touch-action: manipulation
安全区env(safe-area-inset-*)
VPN 功能H5 无法实现真实 VPN，需跳转 App Store/应用市场
广告 SDK接入穿山甲、优量汇等 H5 版本

九、API 接口建议（待后端实现）

9.1 用户模块

POST /api/auth/sms-code      # 发送验证码
POST /api/auth/login          # 登录/注册
POST /api/auth/logout         # 退出登录
GET  /api/user/profile        # 获取用户信息
POST /api/user/delete         # 注销账号

9.2 积分模块

GET  /api/points/balance      # 获取积分余额
GET  /api/points/history      # 获取积分流水
POST /api/points/earn         # 积分获取（广告回调/任务完成）
POST /api/points/exchange     # 积分兑换会员

9.3 会员模块

GET  /api/member/status       # 获取会员状态/剩余时长
GET  /api/member/products     # 获取兑换商品列表

9.4 VPN 模块

GET  /api/vpn/lines           # 获取线路列表
GET  /api/vpn/config          # 获取 VPN 配置
POST /api/vpn/connect         # 连接上报
POST /api/vpn/disconnect      # 断开上报

9.5 分享模块

GET  /api/share/info          # 获取邀请码、分享链接
GET  /api/share/records       # 获取分享明细
POST /api/share/claim-invite  # 领取邀请奖励
